# Proposed copy review: preview.15 visual and dialog updates

**Status: owner approval required. No production strings have been changed.**

This proposal is based on a source review of the garden, profile, copy, sign-out,
deletion, and invitation paths. The suggestions use sentence case, short familiar
words, action-first controls, and only material consequence or privacy context.
The rendered proposal images use synthetic content and do not change application
behavior.

This packet covers the requested high-impact dialogs and the profile/garden
continuity flow. It is not yet a repository-wide inventory of every existing
user-facing string. The editorial gate applies project-wide; additional strings
must be reviewed before any affected change is merged.
