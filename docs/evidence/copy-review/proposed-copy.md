# Bloomstep copy review proposal

**Status: owner approval required. No production UI strings have changed.**

This proposal records an editorial review of the repository's customer-facing
copy sources. It is a proposal only: the screenshots use synthetic data and do
not create invitations, copy gardens, delete data, or change consent. The
review covers the Flutter app and its notifications/tray, the public website
and preview status page, and installer/native labels. User-authored habit text,
provider-supplied names, and server-generated receipt values are data, not
approved product copy; any raw exception or receipt value shown to a person is
called out below.

The visual proposal uses the existing Calm starter recipe
(`After I pour my morning drink, I will take one slow breath. Then I relax my
shoulders and smile.`). “Did it” is rendered inside that same practice card,
not beside an invented habit title. The invitation proposal uses the existing
`PlantArt` and invitation controls. Screenshots show the control heading
`A little growth, together`; the GrowthBook candidate `Share a small beginning`
and its default-off configuration remain unchanged.

## Render evidence

All PNGs under `docs/evidence/visual-quality/proposals/` are synthetic
proposals, not screenshots from an installed build. Profile renders cover
420x820 at 200%, 640x480 at 200%, desktop, missing provider-name fallback,
and expanded garden details. Invitation renders show the existing illustration
and controls at desktop and 200%, including the expanded invite methods, recipe,
and privacy states. The practice card uses the real Calm starter recipe; its
“Did it” control is in the same card and is checked as a semantic button in the
render test.
