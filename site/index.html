Windows first. A real desktop app.

Choose ARM64 for a Windows ARM device, or x64 for Intel/AMD Windows. The app installs for your user account and does not require administrator rights.

Preview installers & checksums

Unsigned preview: Windows SmartScreen may warn about an unknown publisher. Download only from the linked GitHub repository and compare the SHA-256 checksum. Do not bypass security policy on a managed device. Microsoft Store signing does not sign this web download. Store, Android and iOS distribution are deferred.

An update check opens the release page; automatic installation and staged rollout are not yet enabled.

Your habits are private.

What stays on your device

SQLite stores recipes, check-in edits, reflection scores, feedback and settings. Authentication credentials use Windows secure storage, never the database. Your Windows account's filesystem protections apply; SQLite itself is not encrypted.

What sync will send

When the service is live, your authenticated private records sync to the account partition. Feedback and ratings are private, not published to an ideas board. Microsoft, Google or email sign-in is supplied by the configured identity broker.

What we never do

No ads, no AI, no selling habit data. Optional event counts are off by default and contain no habit or feedback text. Invitation links contain no personal garden data.

Export your records as JSON from Settings. Delete local data or request cloud data deletion from the connected app. Cloud deletion keeps a minimal account deletion marker to prevent old devices from restoring your deleted data. Identity provider accounts are managed by their providers, not by Bloomstep.

Planned raw analytics retention is 13 months. No product telemetry is currently collected by this website. GitHub hosts this temporary website and download files and may retain its standard hosting access logs. Azure hosting and a full data-processing notice are required before the public authenticated MVP launch.

Use the private in-app feedback channel for sensitive support once it is connected. Do not place private habits, credentials or account exports in public GitHub issues. Public source and non-sensitive bug reports: Bloomstep repository.
