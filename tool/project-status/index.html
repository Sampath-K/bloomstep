    State definitions and source boundaries

    Planned is an explicitly configured integration gate, not an agent report. Implementing means a draft PR or remote branch exists, not that an agent is currently working. Validating means configured exact-head workflow jobs are pending. Review-ready means those engineering jobs passed, not a human approval or every product gate. Blocked means a failed/cancelled/skipped required check, a closed unmerged PR or unmet prerequisite.

    Merged comes only from the PR API. Released comes only from a published release plus resolved immutable tag. Verified is reserved for the explicitly named exact-release protected workflow gate. A manual gate without a live source remains unknown. Stale evidence cannot satisfy a prerequisite.

    Definitions: tool\project-status\sources.json. Product evidence boundaries: docs\status.md, docs\mvp-exit-matrix.md, docs\experiments.md. Configured notes are historical context, not new observations.
